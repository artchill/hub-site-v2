HUB website v2 - building photo slots
=====================================
Drop real photos here (JPG) using these exact names. The site detects them
automatically and replaces the illustrated skyline. No code changes needed.
If a file is missing, the illustration is used for that spot.

  hero-building.jpg    2400 x 1400   Home hero. City skyline / glass towers at sunrise or
                                     daytime. Keep the LEFT 45% calm (sky) - text sits there.
  banner-building.jpg  2400 x 700    Inner-page banners. Wide office-tower / skyline strip.
  cta-building.jpg     2000 x 800    Call-to-action bands (darkened automatically).
  visual-building.jpg  1200 x 1200   Navy feature card (darkened automatically). Tall tower, looking up.

Tips: keep each file under ~400 KB (compress at squoosh.app). Use photos you are licensed
to use (e.g. your client's own, or free-commercial sources such as Unsplash / Pexels).
Suggested search words: "Cebu IT Park", "Cebu skyline", "glass office building", "business district sunrise".
